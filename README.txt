Tailor Simple App V6

Use the files together. This version keeps the existing Firebase configuration and data model, updates Menu using the supplied menu file, and adds mobile-first layout safeguards.

APK button:
The Menu includes a Download APK button pointing to tailor-manager.apk in the same folder. A web page cannot create a signed Android APK by itself. After you build the APK, upload/host it at that filename (or change the href in menu.html).
